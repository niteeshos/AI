# AI

## Gesture Magic Studio

A tiny web app that uses your live camera feed and MediaPipe Hands to detect hand gestures and trigger animated visual effects in real time.

### Gestures

- **Open palm** → Nebula mode
- **Fist** → Pulse mode
- **Peace sign** → Spark mode
- **Thumbs up** → Flow mode

### Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173> in your browser and allow camera access.
